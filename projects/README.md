# Projects

This directory is reserved for larger systems combining several previously studied concepts. No project is implemented yet.

Planned examples, described in the [roadmap](../ROADMAP.md), include:

- Local LLM CLI.
- Inference benchmark.
- Semantic search engine.
- RAG engine.
- Tool-using assistant.
- Local/offline AI application.

Create a project directory only when implementation starts. Its README should state the user problem, architecture, setup, evaluation evidence, limitations and links to the experiments it builds on. Reusable diagnostics remain in `tools/`; isolated concept demonstrations belong in `topics/`.
