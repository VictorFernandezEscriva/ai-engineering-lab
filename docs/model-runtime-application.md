# Model, runtime and application

The [ecosystem map](ecosystem-map.md) is the central reference for the stack.

- **Model:** architecture plus parameter values define the mathematical transformation.
- **Runtime:** compatible software loads the representation and executes its operations.
- **Application:** user-facing behavior and domain logic choose inputs, interpret outputs and handle errors.
- **Hardware:** physical processors and memory perform and support the computation.

The [LLM fundamentals lesson](../topics/04_llm_engineering/01_llm_fundamentals/README.md) introduces these distinctions. No runtime integration project has been implemented yet.
