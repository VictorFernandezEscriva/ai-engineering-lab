# LLM Engineering

LLM engineering connects language models to useful software systems. It exists because model inference alone does not provide a complete application. It builds on neural-network concepts and adds text representations, runtimes and application interfaces.

## Available material

- [LLM fundamentals](01_llm_fundamentals/README.md)

## Concepts covered

Introductory model/architecture/weights distinctions, tokens, embeddings, logits, sampling, context, runtime and hardware.

## Intentionally not covered yet
