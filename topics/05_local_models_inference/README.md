# Local Models and Inference

**Status: PLANNED (future work).** Corresponds to [ROADMAP Phase 05 — Local Models and Inference](../../ROADMAP.md#phase-05--local-models-and-inference). It has not started: Phase 04 is still in progress and Experiment 30 (autoregressive generation and sampling) comes first. This directory contains no experiments.

Scope, as defined by the roadmap: pretrained models, model loading, inference, context, generation, CPU/GPU inference, RAM and VRAM, and recording model, size, hardware, memory, generation parameters, latency and tokens per second. The roadmap groups the runtime work (Ollama and local APIs, llama.cpp / GGUF, hardware and quantization, benchmarking) as blocks inside this phase.

Later phases build on it: Phase 06 (LLM application interfaces) bridges to usable applications; Phases 07, 10, 11 and 12 form the applied automation and agentic track; Phases 08–09 continue the core track with retrieval and RAG. Each has a planned, README-only directory under `topics/` and nodes in the Learning Cockpit catalog.
