# Computer Vision

Computer vision extracts information from images. Spatial structure motivates local filters and convolutional networks. These experiments apply deep-learning training and machine-learning evaluation to image data.

- [Experiment 08 — Shape CNN Evaluation and Feature Maps](04_shapes_evaluation/README.md)
- [Experiment 09 — MNIST Dataset Loading](05_mnist/README.md)

## Concepts covered

Fixed kernels, feature maps, channels, pooling, synthetic CNN training/evaluation and MNIST loading.

## Intentionally not covered yet

MNIST classification, augmentation, object detection, segmentation and real-image robustness. See the [roadmap](../../ROADMAP.md).

## Status

Existing implementations reviewed. Execution evidence and limitations are recorded per experiment; this is not a claim of field mastery.
